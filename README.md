# TA_for_ONNs

Optical Teaching Assistants for Imperfection-Aware Training of Compact Optical Neural Networks

![img](figure/Fig_TA_for_ONNs.png  "The multi-step knowledge distillation workflow with a DNN teacher, an ONN teaching assistant (TA), and an ONN student on an MNIST instance.")

## Getting Started

### Neuroptica

The `neuroptica` package is obtained and adapted from

```
https://github.com/Xoreus/neuroptica.git
```

`Neuroptica` is a flexible chip-level simulation platform for [nanophotonic neural networks](https://arxiv.org/abs/1903.04579) written in Python/NumPy.

### Teaching Assistants for ONNs

The scripts in `MNIST` and `CIFAR_10` should be run in the order of:

1. Training the DNN-based teacher
2. Training the DNN/ONN-based teaching assistants
3. Training the imperfect ONN students

The results, including the phase configuration of the model and the accuracy of the models, are stored automatically.

### Things to note

1. The CIFAR-10 model logits need to be generated by running `CIFAR_KD_teacher_ResNet9.py`. This has to be performed before running any other script for CIFAR-10.
